# Travel Planning Skill

## Workflow

1. Collect trip criteria including destination, travel dates, party size, and dietary restrictions.
2. Delegate hotel hold requests to the Hotel Specialist Agent through the Agent Gateway PEP.
3. Delegate restaurant candidates to the Restaurant Specialist Agent and apply the `dietary_advisor` skill.
4. Normalize and compare hygiene ratings across regional regulatory frameworks.
5. Initiate Human-in-the-Loop (HITL) task confirmation before finalizing payment authorization.
